> **DIY / own-risk — not a hearing aid or PPE.** Experimental CROS firmware.

**Current:** [pinebuds-cros-v0.3.66.zip](./pinebuds-cros-v0.3.66.zip)

| Package | Role |
|---------|------|
| [pinebuds-cros-v0.3.66.zip](./pinebuds-cros-v0.3.66.zip) | **Current** (v0.3.66) — fw 0.3.65 + Install.ps1 + CROScontrol.apk |
| [pinebuds-cros-v0.3.61.zip](./pinebuds-cros-v0.3.61.zip) | **Audio baseline** |

Each zip includes `Install.ps1` (guided flasher), `bestool.exe`, `CROScontrol.apk`,
flash scripts, `CHANGELOG.md`, and `RELEASE_NOTES.txt`.

**Older builds:** [GitHub Releases](https://github.com/HoldYouClose1988/pinebuds-cros/releases) (not kept in this folder).

Flash guide: [Windows flashing](../docs/windows-flash.md).
